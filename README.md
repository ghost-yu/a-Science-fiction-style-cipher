# a-Science-fiction-style-cipher
A method of encryption that utilises a large language model to generate coherent fiction. Suppose a person could travel back in time from the future to pass on a message to someone they trust.This is the public portion, designed to enable the trusted individual to decrypt the message.

eg:有一天，一个名叫蒂姆的男孩和他的妈妈一起去了商店。蒂姆看到了很多玩具，他感到很高兴。他想把这种不寻常的玩具带给他妈妈看。他问妈妈：“我们能把这个玩具带回家吗？”妈妈说：“是的，你可以拥有它。但是要小心，它很脆弱。”
